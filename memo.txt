# ==========================================
# HWP 이미지 추출기 빌드 가이드 (PyInstaller)
# ==========================================

1. 필수 라이브러리 설치 (최초 1회)
------------------------------------------
# 빌드 도구 및 GUI 패키지 추가
uv add --dev pyinstaller
uv add customtkinter


2. 터미널 버전 빌드 (main.py -> main.exe)
------------------------------------------
# 특징: 실행 시 검은색 콘솔 창이 함께 뜸
uv run pyinstaller --onefile main.py


3. GUI 버전 빌드 (gui.py -> gui.exe)
------------------------------------------
# 특징: 버튼/창 위주, 콘솔 창 숨김, 디자인 패키지 포함
uv run pyinstaller --onefile --noconsole --collect-all customtkinter gui.py


4. 주요 옵션 설명
------------------------------------------
--onefile : 모든 실행 파일을 .exe 하나로 통합
--noconsole : 프로그램 실행 시 배경의 터미널 창을 숨김
--collect-all customtkinter : GUI 테마 및 이미지 파일을 강제로 포함 (필수)


5. 빌드 결과 확인
------------------------------------------
- 생성 위치: 프로젝트 폴더 내 /dist 폴더 안
- 실행 방법: dist/gui.exe 파일을 원하는 곳(바탕화면 등)에 복사 후 더블클릭
- 저장 경로: 
  * 폴더 선택 시: [폴더명]_추출결과 폴더 생성
  * 파일 선택 시: [파일명]_이미지 폴더 생성


6. 기타 팁
------------------------------------------
- 빌드가 꼬이거나 용량이 이상할 경우: 
  /build 폴더와 *.spec 파일을 삭제하고 다시 빌드 명령어 입력
